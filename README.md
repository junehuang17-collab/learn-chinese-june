# Learn Chinese with June

A minimalist Next.js personal website for Learn.Chinese.June.

## Edit your information

Open `data/site.ts`.

You can change:
- Instagram
- Email
- Calendly link
- Payhip link
- Lesson descriptions
- Learning materials
- Student reviews

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy

This project is designed for GitHub + Vercel.

Important: replace placeholder links and placeholder photos before public launch.

## Photo

The first version uses visual placeholders so the site can deploy immediately. Replace the `YOUR PHOTO` blocks later with your own professional photos.
